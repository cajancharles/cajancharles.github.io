01

Overview

This project started with the goal of creating a simple and practical Point of Sale solution for a carwash and auto detailing business without relying on expensive third-party POS software.

The system combines the flexibility of Google Sheets with Google Apps Script and a custom web interface, including a pricing model built around vehicle size rather than a flat rate per service.

Staff can process orders, apply discounts, and take payment through a dedicated POS interface, while a separate receipt page lets any transaction be looked up and reprinted by its transaction ID.

The result is a lightweight business application that can be accessed through a web browser on computers, tablets, and mobile devices — with no server or database to maintain outside of Google's own tools.

02

The Challenge

Traditional POS systems can introduce subscription costs, complicated setups, and unnecessary features for small businesses. A carwash also has needs most generic POS software doesn't handle well out of the box — pricing that changes by vehicle size, mixed carts of individual services and bundled packages, and receipts that may need to be reprinted after the customer has already left.

The goal was to create a solution that could simplify order taking and transaction recording while keeping the underlying data accessible and easy to manage — and editable by a non-technical owner directly from a spreadsheet.

The system needed to provide a better experience for staff while maintaining a centralized, accurate source of transaction data that could survive malformed input, missing optional sheets, and future schema changes without breaking existing records.

03

The Solution

I designed and developed a web-based POS interface that connects directly with Google Sheets through Google Apps Script, with the spreadsheet acting as both the product catalog and the transaction database.

The frontend lets staff select a vehicle size, choose individual services or bundled packages (with prices that update instantly based on that size), add optional add-ons, apply a percentage discount, and calculate change against the amount received.

Google Apps Script handles the backend logic — generating sequential transaction IDs, validating spreadsheet structure, saving transactions and line items, and powering a separate Receipt Printing page where any past transaction can be searched by ID and printed again.

KEY FEATURES

Built around the needs of a real carwash.

01

Vehicle Size-Based Dynamic Pricing

Every service and package is priced across six vehicle-size tiers, from Small to XX-Large. Selecting a size instantly re-prices the entire catalog — no manual lookup required.

02

Services, Packages & Optional Add-Ons

Individual services, bundled packages, and add-ons are pulled live from separate spreadsheet tabs. The Add-Ons tab is entirely optional — the system detects whether it exists and degrades gracefully if it doesn't.

03

Discounts, Totals & Change Calculation

Staff can apply a percentage-based discount with live subtotal and total recalculation, then track amount received and change in real time as payment is entered.

04

Auto-Incrementing Transaction IDs

Every sale gets a sequential, human- readable ID (e.g. DEMO-000042) generated and tracked through a Settings sheet, with a configurable prefix for easy rebranding.

05

Dedicated Receipt Printing Page

A separate, print-optimized page lets staff search any past transaction by ID and reprint a formatted receipt — with UI controls automatically hidden when the print dialog opens.

06

Centralized Reporting Data

Transaction records can be analyzed using Google Sheets, Excel, Power BI, or other reporting tools, including a built-in daily sales and transaction count summary.

07

Data Validation & Error Handling

Every sheet read is checked against required columns before processing, and every numeric or text field is sanitized, so malformed spreadsheet data or a missing column produces a clear message instead of a broken transaction.

08

Spreadsheet-Driven Configuration

Prices, active/inactive products, display order, and even the transaction ID prefix are all controlled from the spreadsheet — a non-technical owner can update the business without touching code.

04

Business Value

This project demonstrates how existing tools can be combined to create a practical business solution without requiring a complex technology stack — or a monthly software subscription.

By connecting a custom web interface to Google Sheets, the business gains a centralized data source while maintaining flexibility in managing products, services, pricing tiers, and transactions directly from a spreadsheet.

The project also creates a foundation for future analytics, allowing transaction data to be transformed into reports and dashboards that can support data-driven business decisions, while the receipt lookup system keeps day-to-day customer service running smoothly.
